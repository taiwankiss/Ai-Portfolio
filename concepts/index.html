AKinetic Index

米白紙感、雜誌編排。超大字級的專案清單就是主視覺，影片跟著滑鼠浮出來。

MICRO-INTERACTIONS

  • 標題上下翻轉成斜體、整列用專案色填滿
  • 游標跟隨的影片預覽（慣性 + 依速度傾斜）
  • 分類篩選、磁吸按鈕、數字 count-up
  • 專案頁：影片開場展開、直向捲動 → 橫向圖庫

BBento OS

現版 Bento 的進化版。深色玻璃質感，像一個作業系統的桌面，資訊密度最高、最好擴充。

MICRO-INTERACTIONS

  • 游標光暈 + 邊框發光、卡片 3D 傾斜
  • hover 播放專案影片、篩選時卡片 FLIP 重排
  • ⌘K 指令面板快速跳專案
  • 專案頁：卡片圖片變形成主影片（View Transition）、可拖曳圖庫

CCinematic Orbit

全螢幕、電影感。專案排成 3D 環狀輪播，背景是模糊的專案影片，一次只看一個。

MICRO-INTERACTIONS

  • 拖曳 / 滾輪 / 方向鍵轉動 3D 環
  • 標題亂碼解碼動畫、底部時間軸 scrubber
  • 專案頁：5 個章節橫向切換，數字圓環填滿
  • 截圖扇形展開、長按圓鈕前往下一個專案

三個方向共用同一份資料 data.js。新增專案時只要多加一筆（標題、一句話、三行步驟、三個數字、截圖、影片），三種版型都會自動排好，不用再寫長篇文案。選定方向後，我會把它接到現有的 build.py 流程，產出可以靜態部署的正式站。
